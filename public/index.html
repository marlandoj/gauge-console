How to read this

The dial shows a complexity tier, not confidence, cost or model quality. Gauge can abstain when the request lacks context or matches no recognized rule.

Harness selection is descriptive. No harness is invoked and no model is chosen. The resolver mapping is identical for all seven harnesses: apex maps to complex; other tiers stay the same.

No task history is stored. Refreshing clears your input. The browser module is pinned to Gauge v0.3.0 and checked for equivalence with the original classifier. Equivalence is not prediction accuracy.

If the controls stay disabled, the engine could not load. Reload the page with JavaScript enabled.
